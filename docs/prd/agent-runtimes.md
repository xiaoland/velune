# Agent 运行时

运行时类型与实例、接入方式（专用 adapter、ACP）、执行位置与 HOME、版本、发现与导入，以及运行时与会话模型、工作目录的关系。

本页维护当前规则；来源链接用于追溯决定，历史表述不单独构成当前要求。产品入口见[产品定义](index.md)。

## 类型与实例

界面使用“Agent 运行时”表示 Harness 类型及其配置实例。Pi Agent 是一种运行时类型；同类型下不同的配置／状态目录等设置形成独立实例，而非一份全局运行时表单。实例身份、配置和会话投影必须区分，具体外部环境变量由适配器转换。此决定不自动要求所有实例并发运行。来源见 [S15](../sources/first-loop.md#s15)。

2026-10-06 用户授权增加 Codex（app-server）与 deepseek-harness 接入，并直接消费 huihua 发行包读取会话，不复制其源码；交付须保留对应开源声明与许可证。同一运行时家族的 breaking-change 版本分别作为独立运行时类型，绑定各自适配器与版本正则，允许多种 Pi 版本同时配置。实际版本匹配用于确认所选类型，不是用一个全局版本闸门替代多版本支持。huihua 是只读会话证据库，不代替原生运行控制接口。

Velune 不随应用分发任何 Agent 运行时，运行时由用户安装、配置或从本机发现；未来的安装运行时功能尚未实施。辅助 adapter 与只读解析依赖可以随应用交付，但不能以 SDK 名义隐含捆绑完整运行时。支持范围必须根据公开版本和实际协议证据决定，公开版本读取失败与已识别但不受支持的版本应明确区分。

运行时设置提供快速导入，检测本机已有可执行入口、实际版本与非秘密实例目录，预览选择后保存；可接续原生提供商／模型导入预览，不把检测当成自动读取登录或调用模型的授权。

### 编辑 Adapter Type

Adapter Type 是实例可编辑的配置；各类型相互独立，不定义升级、继承或兼容关系（[S80](../sources/development.md#s80)）。编辑已有实例可直接更换类型，保留实例 ID、名称和通用执行环境。表单内各类型的专属设置与新建会话默认选择分别暂存，切换类型后不按同名字段继承配置；切回可继续未保存的编辑。保存时只提交所选类型的专属设置，并重新读取历史与能力。原生会话归属不会随普通类型编辑而改写，新类型不能读取的旧记录明确报告不可用；不承诺不同类型的数据互通。

Codex 当前仅支持 `codex-0.166`。退役 `codex-0.159` 的配置和关联由本次一次性显式迁移转换，不建立长期类型迁移关系。

### 配置修改与活动执行

其他实例的活动不阻止新增、保存、启停或删除运行时；只读的提供商导入预览不要求会话空闲（[S61](../sources/dogfood.md#s61)）。生命周期操作只保护实际依赖的执行实例、跨 Harness 来源及后台工作；配置保存按下述 S78 规则处理。

2026-11-04（[S78](../sources/dogfood.md#s78)）：保存提供商、模型路由与运行时配置不要求在途会话空闲，不逐字段枚举许可。当前执行保留准备时的配置和凭据，后续执行准备采用新配置；保存本身不中断当前轮次或其重试。相同提供商的新旧执行共享并发／额度与健康计数，不能因保存配置扩大限额。删除和显式退出登录保留其独立的生命周期保护。改变实例的历史根目录不会自动迁移旧原生会话；新配置无法读取旧身份时明确报错。

### 版本接入

2026-11-03（[S68](../sources/dogfood.md#s68)）：Codex 0.166 改变了恢复及输入的 provider 准入，使用独立的 `codex-0.166` 类型。切换 provider 时保留原始原生会话，以已有上下文接续延续同一个可见会话；不改写旧会话的 provider 身份。新增类型不自动改现有配置；实例与会话关联段通过显式手动迁移一起更新。Pi 1.4 的公开 RPC 没有无消息继续入口；应用保留“继续”，明确发送 `continue` 作为兜底，不发送空消息冒充原生恢复（[S73](../sources/dogfood.md#s73)）。完整提交规则见[输入区](composer-actions.md#发送队列与-steer)。

## ACP

2026-10-10 用户进一步授权通用 ACP Adapter。用户随后澄清，目标是尽可能覆盖更多 Agent Harness，同时避免为每个 Harness 分别开发适配；ACP 是服务该目标的技术方案，不是不可推敲的产品约束。它作为已有专用 Harness adapter 之外的接入方式，使用 Agent 公布的协议能力；平台提供启动配置、模型／会话选项与能力展示。指定参考为 [lexoliu/acpsub](https://github.com/lexoliu/acpsub)，不引入其独立 daemon。

## 原生提供商、网关轮次与执行位置

2026-10-10 用户授权推进 Claude Code、SSH 远程运行时及 Velune 管理的运行时 HOME。运行时不必同时注册多个提供商：保留它已有的提供商，允许会话下一轮选择其原生模型；选择 Velune 管理的模型时，仅该 turn 临时使用 Velune Gateway，结束后恢复原生提供商。成功、失败及取消都必须结束临时覆盖，不修改或删除原 Harness 的持久提供商配置。运行时原生模型的身份属于其具体实例，不能按裸 model ID 当成 Velune 提供商或另一 Harness 的模型。

2026-10-16 用户确认（[S32](../sources/runtime-collaboration.md#s32)）：上述“turn 结束”指该轮的工作全部结束，即轮次本身及其启动、仍在运行的原生子 Agent／后台任务都结束、失败或被用户停止；此前运行时进程与临时覆盖保持，子 Agent 不因父轮次结束被终止。工作未结束时，下一轮若不需要重启运行时照常发送；需要重启（例如换成原生模型、Claude Code 换推理强度）时，先等待子 Agent 结束，或由用户确认停止子 Agent 后发送。父会话的停止同时停止该轮及其子 Agent；轮次已结束、只剩子 Agent 运行时，父会话提供停止子 Agent。

使用原生提供商不阻止跨 Harness 接续。会话的历史来源、下一轮目标运行时和下一轮模型分别表达；切换 Harness 后仍按现有目标原生会话与文本上下文交接机制继续，不能重放原生工具或审批状态。SSH 是运行时执行位置，HOME 是实例环境归属；两者都不改变 Harness 拥有会话历史的边界。Velune 管理 HOME 时不复制用户原有凭据或会话，也不把 HOME 隔离描述成安全沙箱。

2026-10-12 用户要求平台接入这些能力：composer 展示并选择目标实例的原生模型与 Velune 管理模型（通用 ACP 另有 Agent 默认）；运行时设置提供 SSH 运行位置、HOME 归属（继承当前用户 HOME、指定目录或由 Velune 管理）与远端工作目录；按远端文件系统解释会话工作目录。平台消费共享核心的模型身份、能力和失败信息，不自行解析 Harness 配置。

## 会话模型与工作目录

Pi 模型的上下文窗口与输出上限可以未知；未知时由 SDK 使用其原生默认行为，不以强制用户填写能力参数作为执行门槛。实际参数仍以提供商协议为准。Velune 决定当前对话的逻辑模型及 LLM 路由，Harness 应获得执行该模型所需的身份与能力信息。2026-10-06 用户修订运行时默认模型决定：模型选择属于会话，不再要求运行时配置初始模型，也不要求手动连接。已添加运行时即可被选择和浏览其会话；应用按需自动准备执行，浏览历史不依赖模型、凭据或网关准备成功。已有会话的可识别模型选择由 Harness 保存，Velune 恢复并投影；无法识别或已删除的目标须在继续执行前明确选择，不按裸模型 ID 猜提供商，不建立第二份会话存储。运行时启用／禁用可作为额外管理能力，不把它变成手动连接的替代门槛。

工作目录属于具体会话，不属于 Agent 运行时实例。一个实例可在不同项目目录创建和恢复会话。新建可选择“无工作区”：允许空 cwd 的运行时不指定目录，必须有 cwd 时采用执行机器的 `~/Documents/Velune` 并创建必要目录，归入无项目（[S67](../sources/dogfood.md#s67)、[S69](../sources/dogfood.md#s69)）。恢复时沿用 Harness 保存的目录。运行时目录是该实例的配置／状态根目录，具体环境变量由适配器转换，不等同于项目目录。


Pi 新建“无工作区”遵守上述有 cwd 要求的规则，不继承 GUI 根目录。未提供原生自动名称的运行时可按实例开启并选择[自动命名兜底](conversations.md#自动命名兜底)使用的模型；原生已有名称优先。

2026-11-04（[S78](../sources/dogfood.md#s78)）：Codex166 的项目具有原生身份及有序根目录集合。选择整个项目时，创建请求同时提交项目身份和全部运行根，cwd使用首个根；模型环境与写入策略均覆盖所选根。项目身份仅用于归属，不被当作自动授予全部目录的隐含配置。Mac 保留单目录、手输路径及无工作区；整项目选择随Tab创建目标恢复，不进入全局输入内容身份。不支持该项目的运行时或已失效项目保留选择并阻止误发，不静默缩成第一目录。
