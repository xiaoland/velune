# 键盘操作

桌面完整端（Mac、Windows）不借助鼠标也能高效完成日常工作：发送与排队、插入本轮、切换下一轮选择、在会话之间移动、回应审批、阅读与编辑消息。控制端（Android、iPad、iPhone）不在本分册范围内。

各段保留用户决定的原话与日期；同一主题下后来的决定修订先前的表述，以日期较晚者为准。来源见各段标注，产品入口见[产品定义](index.md)。

## 定位与原则

2026-10-26 用户确认 Velune 是 production-grade、heavy-agent-workflow 的 agent shell，桌面端要做到不借助鼠标也能高效使用；开发方提出的 A～F 六组能力全部落地（[S50](../sources.md#s50)）。共同约定如下：

- 每个常用操作都有键盘入口：要么有快捷键，要么能在命令面板中找到。菜单、命令面板与按钮的帮助文字显示同一个当前快捷键。
- 快捷键分作用域：全局命令随时可用；输入区、消息列表、会话列表与审批卡片各有自己的键，只在焦点位于该处时生效。文本框有焦点时，不带 ⌘／Ctrl、⌃ 或 ⌥／Alt 的单键一律交给文字输入。
- 输入法组词优先：组词期间 Return、Esc 与方向键只作用于输入法，不发送、不停止、不切换。
- 不抢焦点：运行时请求、通知和后台会话的变化只提示，不把正在打字的焦点移走；由用户用快捷键过去处理。
- Velune 自己的命令快捷键可在设置的“通用”页中更改、移除或恢复默认；与系统、文字编辑或其他命令冲突时拒绝并说明被谁占用。Mac 用 ⌘，Windows 用 Ctrl，其余遵循各平台习惯（见下文默认表）。
- 速查表（Mac ⌘/，Windows Ctrl+/）列出全部命令的当前快捷键以及各作用域的固定按键。

## 发送、换行与插入本轮

2026-10-26 用户修订发送键（[S50](../sources.md#s50)）：Return 发送、⇧Return 换行，可在设置中改回“⌘Return 发送、Return 换行”。turn 运行中按 Return 照常排队，按 ⌘Return 插入本轮（steer）。据此：

| 发送方式 | 空闲时发送 | 运行中排队 | 运行中插入本轮 | 换行 |
| --- | --- | --- | --- | --- |
| Return 发送（默认） | Return 或 ⌘Return | Return | ⌘Return（⌥⌘Return 同样可用） | ⇧Return、⌥Return |
| ⌘Return 发送 | ⌘Return | ⌘Return | ⌥⌘Return | Return |

Windows 以 Enter、Ctrl+Enter、Ctrl+Shift+Enter 对应上表的 Return、⌘Return、⌥⌘Return，Shift+Enter 换行。运行时不提供原生 steer 时，插入本轮的键退回排队，占位提示说明本轮结束后发送；不模拟 steer。发送方式是应用级设置，作用于所有会话与窗口。

发送快捷键只提交真实正文或附件：空输入时即使按钮为“继续”，发送键也不恢复。继续命令没有默认快捷键，用户可单独配置；它与发送／排队按实时草稿互斥，组词、停止中或请求在途均不可用。完整状态规则见[输入区](composer.md#发送队列steer继续与编辑)。

## 输入区的其他键

- 之前的消息：输入区不做 shell 式的历史调出，↑↓ 在输入框中只移动光标（[S51](../sources.md#s51)）。要重用之前的消息，经大纲或“转到消息”找到它，用消息下方的复制按钮或 ⌘C／Ctrl+C 复制；要改写原消息见[输入区](composer.md#发送队列steer继续与编辑)的编辑消息。
- 排队消息：Mac ⌥↑、Windows Alt+↑ 编辑队列中的最后一条。输入框为空时把它从队列取回输入框（附件一并取回），再次发送即重新排到队尾；输入框有内容时打开该条的编辑表单，不覆盖草稿。队列为空时保留文本框原有的光标移动。
- `/` 命令：在输入框开头输入 `/` 弹出 Velune 命令（切换运行时、模型、推理强度、权限模式，新建会话、继续、停止、添加附件等），继续输入即按命令名、标题与英文名筛选（`/模型` 也找到 `/model`），↑↓ 选择，Return 或 Tab 执行，Esc 关闭。列表浮在输入框上方、盖住其上的内容，不撑高输入区，输入框离开焦点时关闭（[S53](../sources.md#s53)）。需要参数的命令（如 `/model`）进入候选列表。未匹配 Velune 命令的 `/…` 文字按原样发给运行时，由 Harness 自行解释；列出 Harness 原生命令与技能需核心提供运行时声明的命令目录，另行处理。
- `@` 文件：在输入框中输入 `@` 后弹出会话工作目录下的文件模糊搜索，选中后插入相对路径文字（不内联内容）。远端运行时与未定工作目录的会话不提供。
- 附件：Mac ⌘O、Windows Ctrl+O 打开选择文件面板；粘贴图片与文件仍直接成为附件。
- 下一轮选择：各有一个快捷键打开对应的候选列表（运行时、模型、推理强度、权限模式），列表可直接输入筛选，Return 确认、Esc 取消；选择语义与菜单相同（见[输入区](composer.md#选择器与下一轮选择)）。
- 工作目录（Mac）：尚未首发的新会话可经“会话 → 选择工作目录…”、命令面板或 `/cwd` 打开可筛选的目录候选，按项目名和路径匹配，显示当前选择；同一列表提供运行时默认目录、原生选择目录与手动输入路径。composer 收起时命令仍可用；已发送会话不可用。命令无默认快捷键，可在设置中指定。

## 命令面板、打开会话与待处理会话

- 命令面板（Mac ⌘K，Windows Ctrl+K）：列出菜单中的全部命令、设置各页、问题、分析与资源库，以及下一轮选择的各项，显示快捷键；输入筛选，除标题外也按英文名与同义词匹配（[S52](../sources.md#s52)，见 [DESIGN.md](../../DESIGN.md#模式) 的检索别名），如 model 找到“选择模型”，↑↓ 选择，Return 执行，Esc 关闭。`/` 命令与命令面板共用同一套命令定义。
- 打开会话（Mac ⌘P，Windows Ctrl+P）：按标题、项目与工作目录模糊搜索当前列表中的会话（含运行状态），Return 在当前标签打开，⌘Return／Ctrl+Enter 在新标签页打开。
- 转到待处理的会话（Mac ⇧⌘A，Windows Ctrl+Shift+A）：按“等待回应的请求 → 后台结束且未查看的轮次 → 失败”的顺序跳到下一个需要处理的会话；当前会话本身有等待回应的请求时，先把焦点移到它的审批卡片。

## 审批与运行时请求

2026-10-26（[S50](../sources.md#s50)）：运行时的审批与提问显示为会话页中输入区上方的卡片，不再以表单（sheet）弹出，不夺走输入焦点。“转到待处理的会话”或点按卡片使其获得焦点。审批卡片获得焦点时，数字键 1～9 依次选择运行时给出的选项（选项旁标出数字），Mac ⌘⌫、Windows Ctrl+Backspace 取消请求；提问卡片获得焦点时从第一个未回答的问题开始：选择题由数字键 1～9 选择（选项同样标出数字），文字题聚焦其输入框，回答一题后到下一个未回答的问题；全部回答后 Return 提交，Tab 仍可在字段之间移动。标签页与会话列表继续标出等待回应。

## 消息列表

“转到消息”（Mac ⌘0，Windows Ctrl+0）把焦点移到消息列表，选中最后一条消息。焦点在消息列表时：

- ↑↓ 在消息与工作过程之间移动，⌥↑／⌥↓（Windows Alt+↑／↓）在用户消息之间跳转，Home／End（Mac 另有 ⌘↑／⌘↓）到首尾；
- Return 或 Space 展开、收起所选的工作过程；
- ⌘C／Ctrl+C 在没有选中文字时拷贝所选消息的正文，⌥⌘C／Ctrl+Shift+C 拷贝其中最后一个代码块；
- `e` 编辑所选的用户消息（同右键“编辑消息…”，可编辑时才有效），fork 还是原地继续的询问同样可用键盘回答；
- 查找（⌘F／Ctrl+F）与大纲不变。

## 会话列表

焦点在会话列表时，↑↓ 选择并打开会话（与点按相同）；Mac Return、Windows F2 重命名（同双击）；⌘⌫／Delete 删除，仍经确认；直接输入文字转入列表的搜索框并带上该字符。⇥ 或“转到输入区”回到所显示会话的输入区。

## Esc

Esc 按以下顺序只做一件事：结束输入法组词 → 关闭弹出的候选列表、命令面板或打开会话 → 关闭查找栏 → 关闭表单与对话框 → 停止生成。前面的层级存在时不会停止生成。

## 全局唤起与通知

- 全局快捷键“显示 Velune”与“新建会话”在其他应用中也有效，默认不设，由用户在设置中指定，避免与其他应用冲突；新建会话会把 Velune 带到前面并聚焦新会话的输入区。
- 点按通知打开对应会话：等待回应的请求聚焦其审批卡片，其他情况聚焦输入区。
