# Composer 内容、导航与布局

本页定义输入正文、附件、新建会话和导航恢复。下一轮配置见[选择与状态](composer-choices.md)，操作准入见[提交与恢复](composer-actions.md)，技术身份与同步见[输入状态契约](../product-tdd/composer-state.md)。返回[产品能力索引](index.md#能力)。

## 内容与目标的归属

正文与附件拥有稳定的内容身份；运行时、模型、推理强度与权限按目标会话保存。两者分别持久化与跨设备同步。导航恢复关联用于找回内容，当前发送目标另行保存，不能仅按停靠位置或分屏数量推断状态归属。

| 操作 | 正文与附件 | 运行时、模型、推理与权限 |
| --- | --- | --- |
| 同一 group 内切换会话 Tab | 恢复该 Tab 对应的内容 | 恢复目标会话的选择 |
| 只聚焦另一 group 已显示的会话或新建页 | 保留正在编辑的内容 | 恢复新目标的选择 |
| 拆出／关闭分屏、改变停靠位置或收起／展开 | 延续同一内容，保留光标与撤销 | 目标不变时保留选择 |
| 明确执行新建 | 恢复全局唯一的新建内容 | 恢复全局新建选择 |

这是 [S70](../sources/composer.md#s70)、[S71](../sources/composer.md#s71)、[S72](../sources/composer.md#s72) 经 [S78](../sources/dogfood.md#s78) 修订后的规则：跨 group 聚焦保留的只有正文与附件，不能把上一目标的配置写入下一目标。目标尚在加载时，不从旧会话播种配置，也不能向旧执行目标发送。

会话内的输入区和发送 sheet 按会话恢复；sheet 固定目标。共享输入区按上表区分导航与聚焦。队列、审批、工作目录、运行状态和控制权属于目标；drawer 尺寸属于窗口。

## 保存、恢复与保留的输入

未发送正文、附件、明确选择及其恢复关联跨重启保留，包括尚未首发的会话；保存不依赖系统最后提交窗口布局。提交或清空后的空状态也持久化，恢复旧窗口不能使已消费输入重现。删除会话时清理该会话的草稿。来源：[S68](../sources/dogfood.md#s68)。

布局整理不能覆盖或拼接另一份未发送内容，也不产生重复副本。当前没有未完成输入时可使用目的上下文已有草稿；两份内容相遇时都保留，通过“会话 → 保留的输入”或输入区空白处的右键菜单切换。提交只消费当前一份，随后保持空编辑器，不自动调出旧草稿。恢复同一窗口时恢复其输入关联，不根据分屏数量重新选草稿。来源：[S62](../sources/composer.md#s62)，配置归属按上节的 S78 修订。

同一用户的内容、内容恢复关联和目标配置跨设备接续，查看设备身份不能成为内容隔离边界。窗口的 Tab／group、当前目标、光标、撤销与布局不一起同步；撤销只在窗口存续期间保留。按单用户接续设计，不引入多人协作语义。正文、附件或明确选择暂不可用时披露原因、保留编辑并阻止提交；跨端不能静默替换为同名运行时配置。同步与修订规则见[技术契约](../product-tdd/composer-state.md)。

## 新建会话与工作目录

新建进入空消息列表与 composer，不使用 sheet。Mac 的侧栏工具栏、菜单、命令面板等入口在当前 Tab 之后新开标签；当前标签已是未发送的新会话时原地恢复，不叠加空标签。窗口与跨平台标签规则见[工作区布局](workspace-layout.md#窗口与-tab)。来源：[S74](../sources/workspace-keyboard.md#s74)。

新建内容全局只有一份，覆盖参与同步的设备与窗口；新建选择也只有一套，不按项目、运行时、Tab 或 group 另建。明确新建恢复它们，重复进入不清空输入，也不取代普通会话的输入；多个新建 Tab 可以同时查看它们，各 Tab 的项目／cwd 等创建目标独立。

首次发送才创建原生会话。取得原生身份后继续同一输入；只有实际消费了全局新建内容，才为下一次新建换入空内容。借用其他内容创建会话时，不清掉尚未消费的全局新建项；全局新建选择不随内容轮换。首发在途时后来打开的新建页不能随旧创建结果变成已创建会话。创建成功而发送失败时保留原生身份，结果不明时不自动重建或重发。来源：[S71](../sources/composer.md#s71)、[S72](../sources/composer.md#s72)、[S75](../sources/workspace-keyboard.md#s75)、[S78](../sources/dogfood.md#s78)。

仅未首发的新会话可修改工作目录。候选来自执行位置的全部已知项目文件夹，不受侧栏分页、折叠、筛选或最近项目数限制；按项目展示，主文件夹优先，附加文件夹可选，相同路径去重，历史临时 worktree 不自动成为项目文件夹。

- 本机执行：Mac 提供“选择目录…”和“输入路径…”，预填当前路径，允许粘贴及 `~/`；取消不改变选择。
- SSH 或远控：输入执行机器上的绝对路径，不用当前 Mac 的文件面板替远端选目录。
- “无工作区”：允许空 cwd 的运行时不指定目录；必须指定时使用执行机器用户 HOME 下的 `Documents/Velune`，创建必要目录并归入无项目。已有会话的原生工作目录不变。
- 创建／发送前由执行机器检查目录存在且为目录，失败就近说明并保留草稿与路径。

“会话 → 选择工作目录…”、命令面板和 `/cwd` 共用候选与可用性；可搜索项目名或路径、选择无工作区、选择文件夹及输入路径，输入区是否可见不影响命令。目录行为来自 2026-11-02 的细化及 [S67](../sources/dogfood.md#s67)。

## 编辑与响应式布局

输入区以标准纯文本多行编辑为主，不做 Markdown 高亮或富文本格式，不以自动替换、纠错或智能空格改写输入和粘贴。采用平台输入控件的原生文本行为；占位提示与正文排版一致，不增加重复边框、永久说明行或独立占位层。Mac 使用系统文本框外观与焦点环，可随内容增高并缩至一行，长正文在内部滚动。

运行时／模型选择和发送／停止位于编辑框外下方，以紧凑原生控件呈现，不采用聊天式卡片或图标按钮，不各占半个面板。设置入口直接打开对应设置页：运行时到 Agent 运行时，模型到 AI 提供商。大纲入口在详情右侧工具栏。

宽布局把共享输入的发送目标与附件放在编辑块两侧，窄时改为纵向；正文、配置与发送构成的中间编辑块始终居中，两侧内容不把它推偏。Mac 默认占可用宽度的 75%，可选 50% 至 100%，窄窗保留必要编辑空间。配置与提交控件先保持一行，放不下再换行并缩短选择器标题；保留输入入口不占配置行。来源：[S67](../sources/dogfood.md#s67)、[S68](../sources/dogfood.md#s68)、[S78](../sources/dogfood.md#s78)。

底部抽屉记住用户调整的总高度，不因会话、正文长度、加载、锁定或运行状态重新定高。正文与辅助内容在内部受限空间滚动；拖动分隔线调整，双击恢复默认高度。空闲、锁定与生成使用相同编辑框边界；附件与队列按实际内容占用空间，不为一行内容撑满辅助区。来源：[S60](../sources/dogfood.md#s60)、[S62](../sources/composer.md#s62)。

键盘提交与输入法规则归[键盘操作](keyboard.md)，锁定时的编辑边界归[控制权](composer-actions.md#会话控制权与输入锁定)。

## 附件

图片通过各 Harness 原生图片输入交付；其他文件以绝对路径引用附在消息中，由 Agent 自己的工具读取，不内联内容。用户消息中的图片按需加载缩略图，文件显示文件名，可用默认应用打开；原生历史中的图片同样展示。

Mac 原生粘贴支持 PNG／TIFF 图片和 Finder 复制的普通文件，图片同时附带文字表示时按图片处理；纯文字保持原生粘贴行为，文件夹不作为附件。草稿附件可点缩略图或名称用默认应用打开；粘贴图片使用已保存文件，不另建查看器或复制预览文件。查看与移除分别判断资格，禁止编辑不等于禁止查看。侧聊遵守自身能力，当前不接收附件。来源：[S64](../sources/dogfood.md#s64)。
