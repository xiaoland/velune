# 多窗口、标签与布局

本页拥有窗口、分屏标签组、停靠区、工具窗口及布局恢复。下文以 Mac 表述；Windows 按[平台与界面](platforms.md)取得一致的完整端结构。输入内容与执行配置的恢复归[Composer 内容与导航](composer-input.md)，不由窗口布局决定。

## 窗口与 Tab

每个窗口保存自己的导航、加载状态与阅读位置；配置与执行核心共享，打开历史不改变其他 Tab 的执行上下文，发送明确绑定目标会话。关闭 Tab 不等于停止其他 Tab 的工作，运行生命周期归[Agent 运行时](agent-runtimes.md)。

编辑区的每个分屏是标签组，可同时打开多个会话，标签可在分屏和窗口间移动。会话窗口不使用系统窗口 Tab：系统 Tab Bar 无公开接口可放进各分屏，与分屏标签叠放又会角色重复；标签只保留分屏内这一层，多个工作区使用多个窗口。标签栏始终显示，外观仿系统 Tab Bar，不另加强调色激活条；标题已在标签上，工具栏不重复。来源：[S26](../sources/workspace-keyboard.md#s26)、[S28](../sources/workspace-keyboard.md#s28)、[S67](../sources/dogfood.md#s67)。

Mac 与 Windows 新建会话在当前标签之后新开 Tab，当前已是未发送的新会话时原地恢复。首次发送与全局新建状态见[新建会话](composer-input.md#新建会话与工作目录)。来源：[S74](../sources/workspace-keyboard.md#s74)、[S76](../sources/workspace-keyboard.md#s76)。

“重新打开关闭的标签页”按关闭逆序恢复：会话在当前标签之后重开，未发送的新会话重开为新的新会话，已删除会话跳过；侧聊随来源结束，不进入历史。Mac 使用 ⇧⌘T，Windows 使用 Ctrl+Shift+T，关闭／新建等完整键位归[键盘操作](keyboard.md)。来源：[S76](../sources/workspace-keyboard.md#s76)。

标签与会话列表共用同一份会话操作和准入：发送、侧聊、继续／停止、重命名、置顶、已读、项目、归档、打开、复制及删除。标签另有关闭、拆分和移窗操作，呈现未读／失败／运行／待答状态。跨会话管理进度放窗口工具栏。Artifact 复用编辑区和拖动机制，内容规则归 [Artifact](conversation-view.md#artifact)。来源：[S69](../sources/dogfood.md#s69)。

## 窗口系统

窗口支持高工作负载与信息负载，默认保持简单，进阶能力按需出现；不追求任意内容皆可停靠组合。变更审阅暂缓，跨会话活动面板不做；是否启用变更审阅及是否管理 git worktree 仍需另行决定。来源：[S25](../sources/workspace-keyboard.md#s25)。

- **编辑区**：可左右／上下分屏，每个面板有自己的会话和运行状态，可拥有各自输入区，也可使用共享输入区。分屏可拖出成独立窗口或拖回，系统窗口平铺可继续使用。
- **停靠区**：编辑区外有左／右／底三个区域，工具可放任一区，同区可并排。工具窗口限于会话列表、大纲与 composer，共用位置、模式、可见性、尺寸状态和操作。
- **工具模式**：停靠、浮动、独立窗口或隐藏。独立窗口可进入 Mission Control、移到其他屏幕或全屏；浮动面板贴近主窗口或彼此时吸附，随主窗口移动，拖入停靠区恢复停靠。
- **会话独立窗口**：默认只含编辑区、标签、分屏和各自输入区，没有会话列表等停靠区；标签可与其他窗口互拖，需要时可恢复停靠区。
- **尺寸与置顶**：分屏、停靠区、区内工具之间的分隔可拖动，双击恢复均分或默认；窗口可保持最前。

拖标签到分屏边缘即拆分，拖到窗口外即新建会话独立窗口，右键菜单提供同样操作。工具位置、底部区、仅显示编辑区、置顶也可在标签和工具右键菜单操作，会话列表的位置在“显示”（筛选）菜单调整，不依赖菜单栏。来源：[S26](../sources/workspace-keyboard.md#s26)、[S28](../sources/workspace-keyboard.md#s28)。

从全屏窗口明确新开的窗口以普通窗口展示，之后可由用户进入全屏；恢复窗口仍遵守系统恢复语义。列表会话拖入已有标签或面板时，只在目标打开，不能同时触发拖出新建窗口。来源：[S67](../sources/dogfood.md#s67)。

右侧区／底部区和标签切换采用熟悉的桌面快捷操作；Velune 命令可在设置更改、移除或恢复默认，键位以[键盘操作](keyboard.md)为准。收起底部区时其中的 composer 一起隐藏。来源：[S38](../sources/workspace-keyboard.md#s38)。

## 布局恢复与输入边界

布局自动恢复，不提供命名布局。工具的位置、可见性、停靠区和尺寸始终保存；没有自身布局的工作区窗口沿用最近工作区安排。新建的会话独立窗口采用自己的默认工具布局，输入区跟随详情，不继承主窗口停靠或收起状态。来源：[S33](../sources/workspace-keyboard.md#s33)、[S73](../sources/dogfood.md#s73)。

已有窗口优先恢复自己的 groups、Tab 顺序、选中、焦点和工具状态。默认工作区的回退恢复不能使用会话独立窗口快照。尚未载入的后台 Tab 也保留恢复信息，恢复时即按保存的会话身份展示标题，内容可延迟读取，标题不能等首次点开才出现。系统决定重开哪些原生窗口，Velune 为默认工作区保存编辑区恢复点。来源：[S73](../sources/dogfood.md#s73)、[S75](../sources/workspace-keyboard.md#s75)。

布局整理延续当前内容，目标不变时保留选择；同 group 导航与跨 group 聚焦采用不同恢复规则。正文／附件与目标配置各自跨设备接续，窗口的布局、焦点、光标和撤销保留本地。新建只有全局一份内容及选择，不按窗口或 Tab 再建一份。完整规则只在[内容与导航](composer-input.md#内容与目标的归属)维护，以 [S78](../sources/dogfood.md#s78) 对早期窗口自持输入规则的修订为准。

底部抽屉沿用用户调整的高度，composer 状态、草稿或目标变化不重新定高；正文和辅助内容内部滚动，具体一行最低高度与尺寸规则见[编辑布局](composer-input.md#编辑与响应式布局)。
