# 消息展示

会话详情中的消息布局、Markdown 与链接、工作过程折叠与大纲。

本页维护当前规则；来源链接用于追溯决定，历史表述不单独构成当前要求。产品入口见[产品定义](index.md)。

## 布局与渲染

会话按来源区分两侧：用户及客户端扩展通知在右侧，LLM、工具与运行时状态在左侧。背景通知有独立的 client 身份，不作为用户新轮次或大纲条目。该规则由 [S73](../sources/dogfood.md#s73) 修订先前按系统角色居中的呈现。不显示用户或 LLM 的头像、昵称等身份标签，也不将 LLM 消息标记为 Velune 发出。Velune 品牌不作为 LLM 的身份。来源见 [S15](../sources/first-loop.md#s15)。

会话标题采用可读内容而非 transcript 文件名，时间按平台本地格式呈现。打开会话来到底部，发送和流式追加跟随最新内容，同时允许用户阅读历史。长会话采用懒加载或复用列表，避免每次更新重建全部消息视图。用户内容显示为右侧气泡；LLM content 与工具在左侧左对齐，系统／Harness状态保持独立。LLM content 按完整 Markdown 渲染，复用成熟 Swift 组件并遵守其开源许可。消息中的网页和本地文件链接可交给系统打开，相对文件地址以该会话工作目录解析；无法打开时显示原始链接并允许复制。大纲跳转应对齐实际目标消息，不因懒布局估算停在相邻消息。2026-10-26（[S51](../sources/workspace-keyboard.md#s51)）：用户消息与每轮最后的回复下方各有一个复制按钮（工作过程中的消息与正文没有），指针停在该消息上时出现，复制整条消息的正文与提示（不含思考、工具输出与附件）；按钮的位置预先留出，出现时不推动内容。

## 工作过程与大纲

消息展示支持工作过程折叠与用户消息 outline。工作过程折叠块与内容列内的LLM／工具消息左边缘对齐，不按系统状态居中。2026-10-11 用户纠正折叠区间：消息列表呈现为“用户消息 – 工作过程 – Agent 回复”：回复只指区间最后一条 assistant 消息末尾的正文文本，不含思考；该消息中位于回复之前的思考、工具等块与其他中间消息一并归入工作过程，末条不以正文结尾（例如以工具调用或工具结果收尾）时整段为工作过程、没有回复。

工作过程以用户消息为锚，完整覆盖下一条用户消息之前的响应；单条正文完成不能截断后续工具及答复的折叠归属。纯正文可流式外露，执行结束由Agent运行时的生命周期确定。时长仅来自实际观察到的执行区间，缺失时显示“工作过程”，不能伪造耗时。2026-10-12 用户要求：未结束的 turn 默认展开工作过程；运行中的表达参考 Claude Code／Codex App（如最新思考摘要的 shimmer），但优先贴合原生常见模式；“可能正在 Velune 之外运行”的说明文字多余，只保留进度指示即可；composer 并列的弹出按钮不用强调色指示器，改用中性色。同日用户补充：运行中 turn 的思考块不自动展开；有思考摘要时以摘要作为思考块的标题，没有摘要时不显示思考块，不出现通用的“思考过程”折叠项。

### 大纲与阅读定位

大纲以用户消息为条目，有两种呈现，由设置中的“大纲按钮”选项决定点击详情右侧工具栏大纲按钮的行为（2026-10-10 用户纠正：此设置不是消息列表的默认显示模式）：“弹出面板”在按钮处弹出原生 popover，大纲项单击选择，双击直接前往，并保留显式前往按钮；“就地折叠”把消息列表以动画原地缩起为只剩用户消息，按钮呈选中状态，再次点击或点击某条用户消息即恢复完整列表并停在该消息，所在位置在动画中保持稳定。折叠只是临时阅读状态，切换会话或发送消息后恢复完整列表。回到底部保留在消息列表浮动操作区并只使用向下箭头，采用与整体一致的标准矩形按钮，与滚动条保持合适间距。

大纲跳转定位实际用户消息，让用户气泡底部与消息滚动视口底部对齐；复制控件和整轮工作过程不作为定位端点。懒布局估算不能让目标随后漂移（[S69](../sources/dogfood.md#s69)）。

## 上下文压缩状态

2026-10-27 用户要求展示“正在压缩上下文”这样的 Harness 状态。实际开始、完成、失败或取消由运行时确认，以独立系统状态呈现；工作过程折叠时仍可见，也不把原来的最终回复收进工作过程。控制连接断开或执行结束时不得留下过期的进行中提示，没有成功确认时不得显示压缩成功。重新打开会话时只恢复原生保存的压缩记录。

2026-10-30 修订（[S59](../sources/dogfood.md#s59)）：完成的压缩、轮次中的错误及重试记录按发生顺序归入该轮工作过程；即使状态在 assistant 正文之后到达，也不留在回复下方、不改变最后正文的回复归属。尚在进行的压缩保留可见状态，完成后进入工作过程。只有确认正常完成的 turn 才自动折叠工作过程；失败、停止或没有结束证据时保持展开，用户仍可手动折叠。单条消息完成、控件不再显示运行或压缩完成都不代表用户 turn 正常完成。

主动发起的上下文维护独立于上一用户轮次，成功、失败或取消后仍单独可见；只有执行中的自动压缩才在完成后归入该轮工作。不明历史归属保持独立。

## Artifact

2026-11-03（[S69](../sources/dogfood.md#s69)）：Mermaid fenced code block 保持可读、可复制的源码，在“复制”旁提供“查看”。查看默认打开 sheet；sheet 的标题可拖到标签栏、分屏或窗口外，也提供移到标签页／新窗口的显式操作。内容统称 Artifact，内容类型与展示位置独立，后续格式沿用同一承载机制。

首轮在 Mac 实现 Mermaid。Artifact 保存来源和源码快照，重复查看同一来源的同一内容复用已打开对象；移动后继续当前源码／图表选择。已放入编辑区的 Artifact 随窗口布局恢复，sheet 是临时呈现。Artifact 没有 composer、原生会话或执行生命周期；会话发送、停止等命令不能落到它背后的会话。图表本地渲染，可缩放、切换源码及复制；语法错误就地显示。查看不加载图中外部资源或执行图内导航。

## 消息操作行

用户消息、工作过程底部与最终 assistant 回复使用消息操作行（message hover bar），放置复制等操作；创建时间和复制／编辑／分叉随消息悬停显隐（[S73](../sources/dogfood.md#s73)、[S78](../sources/dogfood.md#s78)）。真实消息的创建时间与复制按钮相邻，以本地时区显示：当天为 `HH:mm`，当年其它日期为 `MM-dd HH:mm`，跨年为 `yyyy-MM-dd HH:mm`；缺失原生时间时不编造。工作过程分组没有独立创建时间，不在其尾部或最终回复顶部另放时间。该行不承载应用全局任务进度。

2026-11-04：可编辑的用户消息在操作行复制旁提供编辑按钮（铅笔图标），指针停留在该消息上时出现，打开与右键“编辑消息…”相同的编辑表单，同样提供原地或新会话继续的选择。原生可分叉运行时（Codex／Claude Code／Pi）的会话中，每轮最终回复的操作行在复制旁提供分叉（fork）按钮，指针停留在该消息上时出现。点击后以该轮结束处为边界创建新会话：新会话包含该轮及之前的全部内容，原会话不变，新会话在新标签页打开并等待下一条输入；最后一轮的分叉等于复制整个会话当前分支。分叉经各 Harness 的原生机制执行（Codex `thread/fork`、Claude Code `--fork-session`、Pi fork/clone），Velune 不复制或改写原生历史；Claude Code 的分叉与新建会话一样在首轮发送时才产生原生会话文件。运行中、待审批、有未发送草稿、sub-agent 会话与跨运行时组合视图不提供该按钮；DeepSeek、ACP 等无可靠分叉机制的运行时不提供。
