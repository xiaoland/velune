## 分析

2026-10-07 用户授权新增“分析”，参考 Magpie、ccusage 和 sub2api 的分析能力，帮助用户深入浅出地了解自己的 token 消耗与运行表现，包括 token/s 等性能指标。界面须遵循平台原生体验，概览可以继续展开到统计口径与具体记录；消耗、性能和费用的来源与未知项必须可辨认，不把 token 消耗或生成速度当成模型输出质量。参考工具的全部功能不自动成为 Velune 的首版范围。具体数据来源、统计边界和实施切片由任务继续核对。

2026-10-07 用户要求整顿主窗口控件堆叠并重新审查分析UI/UX。常用操作应与其作用内容相邻，应用级入口不能和下一轮发送参数争夺同一层级；统计概览、来源比较与具体请求各有清楚阅读层级，不能通过嵌套滚动或自动挤出的详情影响使用。未知计量、报告覆盖率和当前范围应随数据可辨认；刷新不应丢失已有阅读位置或将旧数据错误标成新范围。

## 用量与来源

同一个分析窗口的概览与提供商／模型分解同时呈现网关记录和提供商用量。来源、范围、覆盖和截止时间随数据展示；重复范围只比较一次。提供商用量可能已包含网关请求，两类数字并列供核对。请求详情、请求结果和性能由网关记录提供。

ChatGPT 订阅读取账户的累计 Token、日期用量和来源支持的模型明细。个人订阅可能提供相对用量、credits 或轮次，支持的工作区还可报告按模型的输入、缓存及输出 Token。OpenAI Platform、Anthropic API 复用已保存的组织查询配置，读取本月按日、按模型的用量及费用。保留来源日期和实际覆盖区间，按各自的单位呈现 Token、相对用量、轮次、credits 和币种。

同一真实账户的重复提供商配置只计一次。组织全量与其子范围有重叠时不相加；不能证明范围互斥时保留明细并说明未合计的原因。汇总显示已知覆盖情况，缺失、失败与未配置保持可辨认，不把未知当作零。刷新时保留已有数据，过期数据明确标记，部分来源失败不隐藏其他成功来源。

credits 余额与 banked reset 权益属于账户快照，和历史消费分别呈现；不能由余额差额补造用量，也不能把权益次数计作货币或 Token。具体账户行为见[订阅 credits 与重置权益](ai-providers.md#订阅-credits-与重置权益)。
