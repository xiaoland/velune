## 分析

2026-10-07 用户授权新增“分析”，参考 Magpie、ccusage 和 sub2api 的分析能力，帮助用户深入浅出地了解自己的 token 消耗与运行表现，包括 token/s 等性能指标。界面须遵循平台原生体验，概览可以继续展开到统计口径与具体记录；消耗、性能和费用的来源与未知项必须可辨认，不把 token 消耗或生成速度当成模型输出质量。参考工具的全部功能不自动成为 Velune 的首版范围。具体数据来源、统计边界和实施切片由任务继续核对。

2026-10-07 用户要求整顿主窗口控件堆叠并重新审查分析UI/UX。常用操作应与其作用内容相邻，应用级入口不能和下一轮发送参数争夺同一层级；统计概览、来源比较与具体请求各有清楚阅读层级，不能通过嵌套滚动或自动挤出的详情影响使用。未知计量、报告覆盖率和当前范围应随数据可辨认；刷新不应丢失已有阅读位置或将旧数据错误标成新范围。具体Mac布局和验证归[体验整顿任务](../../tasks/mac-navigation-refinement/packet.md)。
