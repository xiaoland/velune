# 输入区（composer）

输入区是正文编辑、下一轮执行选择与会话操作的入口。按要解决的问题读取对应分册；分册记录当前规则，历史决定通过来源编号追溯，无须再按日期叠加推导。

| 问题 | 权威分册 |
| --- | --- |
| 内容归属、导航与跨设备恢复、新建、工作目录、布局、附件 | [内容与导航](composer-input.md) |
| 模型／推理／权限、会话当前与下一轮、速度、额度 | [下一轮选择与状态](composer-choices.md) |
| 发送、排队、steer、继续、编辑、压缩、恢复、控制权 | [提交与恢复](composer-actions.md) |

产品入口见[产品定义](index.md)，共享身份与修订见[技术契约](../design/composer-state.md)。以下保留原章节入口，已有链接可直接定位到新 owner。
