VELUNE — SVG LOGO KIT

15 transparent, true-vector SVG files: three optical masters in five colorways.
Each file contains two editable cubic-Bézier paths, no embedded raster image,
no fonts, no scripts, no gradients, and no external dependencies.
All files use viewBox="0 0 1024 1024". Set width and height together.

WHICH MASTER TO USE
Small: 16–31 CSS px, including 16, 20 and 24 px UI icons.
Medium: 32–95 CSS px, including 32, 48 and 64 px icons.
Large: 96 CSS px and up, presentations, marketing and print.
Choose by displayed size, not the number of device pixels on a Retina display.
Below 16 CSS px the interlocking detail is not guaranteed to remain legible.

OPTICAL CORRECTIONS
Large reconstructs the approved raster silhouette with smooth editable paths.
Medium separates the two pieces by 12 additional units horizontally and opens
and smooths the inner return by approximately 7 units (1024-unit coordinate grid).
Small separates the pieces by 32 additional units horizontally, moves the right
piece up 3 units, opens the return by approximately 18 units and simplifies its
curvature. The left return is also slightly softened. These are distinct path
geometries, not rescaled copies. The shared canvas and overall V identity remain.
The small master intentionally reads a little wider; do not replace all sizes
with it. Fine appearance still depends on browser rasterization and background.

COLORWAYS / FILE SUFFIXES
- graphite: left #232629; right #737E89. For light backgrounds.
- dark: left #E9EDF2; right #9DA7B3. For dark backgrounds.
- black: both #000000. For light backgrounds / one-color reproduction.
- white: both #FFFFFF. For dark backgrounds / reversed one-color reproduction.
- theme: both #7686B5. Approved theme accent, best on light backgrounds.
Backgrounds in the PNG preview are demonstration surfaces only; SVGs are transparent.

FILES
velune-{small|medium|large}-{graphite|dark|black|white|theme}.svg
Example: velune-small-graphite.svg for a 20 px light-theme app icon.

RECONSTRUCTION NOTE
The supplied reference was a raster image, not the original vector artwork.
The large master is a careful geometric reconstruction, not an exact recovery of
original control points. Its silhouette overlaps the raster mask by approximately
99% at source resolution (threshold-dependent). Raster texture and shading are
intentionally replaced with flat approved fills. Medium and small deliberately
modify the gap and curve positions for optical clarity.

PREVIEW AND VALIDATION
The comparison sheet shows all fifteen variants at 256 px and native specimens
at 16/20/24, 32/48/64 and 96 px. The SVGs were rendered and inspected; all contain
exactly two independent paths, the same canvas, and no clipping or dependencies.
