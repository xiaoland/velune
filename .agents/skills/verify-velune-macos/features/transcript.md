# 会话消息列表

## 操作范围

检查新增消息行的可见顺序、AppKit 辅助功能顺序，以及后台切换缩放后返回同一会话的重排。

## 用户入口

打开会话标签看历史和新消息。切另一标签后修改外观缩放，再返回原会话。

## 用原生检查复验

```sh
python3 scripts/check-macos-composer.py transcript --app "$app" --output "$out"
```

核对 `PASS native transcript`。真实 AppKit 行和辅助功能元素顺序应与模型相同，中间插入和撤去一行应复用其他单元格，返回后按新字号布局。

## 易漏条件

检查从受控的消息模型变化开始。远端游标、增量合并和负载恢复应在产生与接收这些更新的层复验。
