# Mac Agent 操作指引

本文件面向修改或验收 Mac 端的代码 Agent。实现与构建入口见 [README](README.md)，实例用途和启动工具的机制见[开发实例隔离](../../docs/development/environment.md#mac-开发实例)。

## GUI 与进程范围

普通 GUI 经 `svc run start-macos-dev`／`status-macos-dev`／`stop-macos-dev` 管理，不裸执行 bundle 内文件，不按名称批量结束 Velune，也不退出日常实例来释放开发目录。既有 `--check-*` 程序化入口可直接运行开发可执行文件，但须使用私有合成目录，保留本次子进程句柄且只回收该子进程；运行回执不是对某个 PID 永久有效的退出权限。

同工作树可复用明确的开发实例；需要独立 UI 时使用不同 worktree／scope。日常重装会退出正在使用的应用，仍由用户在应用外执行。

## 焦点与验收证据

隔离数据与后台启动不等于不会改变桌面焦点。验收不得默认显示、激活或抢占用户窗口；只有用户明确要求前台验收时才使用可见检查。入口提供显式前台许可参数时须一并传入，例如支持 `--allow-foreground-check` 的入口。

运行前检查具体入口及其 SwiftUI/AppKit 生命周期。不把 `isActive == false`、隐藏宿主或事后窗口断言单独当作全程不干扰的证据。用户要求不触桌面而尚未确认安全路径时，只做源码与编译，明确尚未完成的视觉／交互验证，不以被否定的旧截图替代当前验收。

实际查看当前产物后再判断视觉结果；脚本的“通过”标签不代替查看。按[验证说明](../../docs/development/validation.md)区分离屏渲染、本地控件调用、系统键盘与 AX 覆盖范围。
