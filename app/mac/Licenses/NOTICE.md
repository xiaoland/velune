Velune Mac 使用以下 Swift Package Manager 依赖，完整许可证随应用打包：

- MarkdownView 3.0.0，https://github.com/LiYanan2004/MarkdownView，MIT。
- swift-markdown 0.9.0，https://github.com/swiftlang/swift-markdown，Apache 2.0 与 Swift Runtime Library Exception。
- Highlightr 2.3.0，https://github.com/raspu/Highlightr，MIT（含 highlight.js 资源）。
- RichText 1.0.0，https://github.com/LiYanan2004/RichText，MIT。
- SwiftMath 1.7.3，https://github.com/mgriebling/SwiftMath，MIT（数学字体声明见随附许可证）。
- swift-cmark 0.9.0，https://github.com/swiftlang/swift-cmark，BSD 与 MIT，见 COPYING。

版本与提交由 Package.resolved 锁定。仅消费上游包，不复制或修改上游源码，不构建或运行上游测试。SwiftPM 资源 bundle 随应用分发。
