# Velune Mac app

本 unit 使用 SwiftUI／AppKit 的原生窗口、会话列表、聊天投影和设置界面。品牌只出现在图标与少量内容细节中。

app 通过生成的 UniFFI 接口消费 application 的完整用例，不解析 Pi RPC，不自行启动网关，也不承担跨包失败补偿。应用配置根为 `VELUNE_HOME`，默认 `~/.velune`；提供商 API key 由 application 私有配置保存，OAuth 保留原来源刷新。各 Harness 拥有真实会话持久化。

构建与本地安装入口为 [build-macos.sh](../../scripts/build-macos.sh)。真实登录、提供商调用和体验由用户验收；静态检查与隔离合成验证归 [开发说明](../../docs/development.md)。

运行时设置展示 family、精确版本类型与配置实例，当前提供 Pi 1.0.2、Codex 0.159.3 和 DeepSeek Harness 0.2.0-rc.2。同类型可保存多个实例，工作目录属于具体会话。App 只消费通用消息与类型化权限／回答交互，不解析 ACP 或 app-server envelope；选择、回答和取消通过生成接口交给 adapter。运行时要求外部 Node 22.19+ 的绝对路径；Pi、Codex 与 DSH CLI 均由用户外部安装并配置。添加实例后即可浏览会话，新建表单选择实例／模型，目录可选；Mac首次发送才准备运行时并创建原生会话，继续历史时自动准备。恢复 Codex／DSH 缺少提供商身份的模型选择须明确指定，不宣称恢复上次 Velune 路由。

构建前只需安装 runtime-support，huihua parser 依赖及许可证随 bundle 打包；不分发 Agent runtime 或完整 Pi SDK。具体步骤见 [开发说明](../../docs/development.md#原生运行时与历史读取)。构建产物不等于已安装或用户验收，最终状态以任务记录为准。

会话内容消费 Rust 的类型权威，Mac 只派生展示行与展开、滚动状态。用户内容在右侧气泡，assistant 正文及工具左对齐；系统通知居中，工具输出不按 LLM Markdown 解析。Markdown 由固定 SwiftPM 依赖 swift-markdown 解析，许可证随应用分发；不恢复手写 fence 解析。虚拟列表使用稳定行身份，打开／发送到底，阅读历史时暂停流式跟随。当前实施与验收见 [展示任务](../../tasks/conversation-presentation/packet.md)。

Mac 最低支持macOS15，由根目录 [Package.swift](../../Package.swift) 定义独立 SwiftPM 产品，依赖固定 swift-markdown 0.9.0；[Package.resolved](../../Package.resolved) 锁传递依赖 swift-cmark。build-macos 先生成 UniFFI 模块，再以SwiftPM的Xcode后端构建本机架构release产品，应用与生成绑定目标各自启用warnings-as-errors，并打包`app/mac/Licenses`与解析锁文件。依赖保持各自声明的Swift语言模式；当前依赖没有资源bundle。Swift 包不依赖领域 Rust 包源码，只链接对应生成绑定与库。

会话上下文菜单按运行时能力提供重命名和永久删除确认。选中目标、待加载身份与已加载详情分别管理；加载时显示进度，暂停其它选择并隔离旧轮询，失败恢复原会话。操作交给生成绑定和运行时执行，不建立 Mac 标题覆盖存储。隔离验收见 [会话管理任务](../../tasks/session-management/packet.md)。

侧栏浏览全部启用运行时的会话；“显示”菜单提供运行时／项目分组与显式筛选，创建／更新时间排序和方向。分组依据完整原生 CWD，不将同名目录合并；未知时间放最后。浏览选项不选择执行实例。加载只限制普通行选择，原生菜单及管理提交保持可用，并显示等待或执行状态。当前切片不提供自定义标签记录；范围见 [统一浏览任务](../../tasks/conversation-browser/packet.md)。 分组、运行时／项目筛选和时间排序偏好随应用配置保存，重启恢复；搜索文字和额外加载页仅属于本次浏览。

所有可编辑列表采用原生双击主操作：提供商、运行时、模型模板打开编辑，提供商内模型聚焦对应详情，会话打开原生标题重命名。单击选择与 ⌘／Shift 多选保持有效；只读目录或导入候选不伪造编辑操作。

“问题”是共享 AppStore 的原生窗口，可从主窗口有问题时的状态入口、编辑／导入 sheet 标题行或菜单“问题…”打开（⌘⇧M）。操作失败保留结构化诊断，不在 composer／设置底部或会话列表重复展示；活动读取问题按来源合并，恢复时移除。记录在当前进程内最多保留100项，不作为第二套日志或持久化数据。具体验收和安装状态见 [问题展示任务](../../tasks/problems-surface/packet.md)。

消息列表消费 Rust 的 `TranscriptTurn` 引用，保留用户问题与当前最后结果，其余工作消息可展开查看。详情右侧工具栏提供会话大纲，设置“大纲按钮”决定其行为：“弹出面板”在按钮处弹出原生 popover 列出用户消息；“就地折叠”使按钮成为开关，消息列表以行高插值动画缩起为只剩用户消息，点击其中一条或再次点击按钮即恢复完整列表，锚点消息在动画中保持屏幕位置，减少动态效果时直接切换。折叠是临时状态，切换会话或发送后恢复；工作过程等展开状态在折叠期间保留。回到底部的向下箭头仍在消息列表内，右边距按当前滚动条样式让出滚动条宽度。展开状态按消息／turn 身份保存，权威历史替换时清理失效引用，不能将当前位置保存为固定数组下标。

问题窗口完整展示传入的本地错误原因、阶段与诊断编号；开发工具的真实数据读取限制不构成应用对用户诊断的过滤规则。窗口记录仍是当前进程内的有界问题集合，不是原始日志浏览器。

主窗口的下一轮运行时／模型选择位于输入区，与历史来源独立；侧栏工具栏保留浏览筛选，新建会话（⌘N，直接进入空会话与空输入区，不弹 sheet）归侧栏工具栏，大纲归详情右侧工具栏，分析不占主窗口工具栏。从“显示 → 分析…”打开独立窗口，其概览、提供商与模型、请求页分别承载摘要、来源比较与明细。表格双击推进只读请求详情，不触发编辑。查询的最后成功范围与数据一起保存，刷新和失败不错误重标旧数据。分析验证归[体验整顿任务](../../tasks/mac-navigation-refinement/packet.md)，最新输入区与工具栏调整归[输入区任务](../../tasks/composer-pi-send/packet.md)。

整个底部输入面板由原生 NSTextView 编辑区与其下方一条操作行组成：编辑区采用标准文本框外观（系统背景、边框与焦点色焦点环；滚动视图会裁掉文本视图自身的焦点环，因此按系统样式在框外绘制，仅在窗口为主窗口时显示），占位提示与正文同一排版，高度随内容增长至上限后滚动；输入、输入法组字文本与占位提示使用同一字体和固定行高（组字文本沿用输入法的下划线，字体与行高由编辑区统一，避免候选列表出现时整行位移）；纯文本编辑，关闭智能引号／破折号、文本替换、自动纠错、链接与数据检测和智能空格；草稿、下一轮运行时与模型按会话保存（草稿经核心持久化，撤销历史按会话分开），新窗口与新建会话后焦点落在输入区。操作行左侧提供按标题宽度显示的运行时／模型弹出按钮，直接选择并在菜单末尾打开设置中对应的页（运行时→Agent 运行时，模型→AI 提供商）；尚未首发的新会话在同一行多一个工作目录菜单；长名称截断显示，帮助和辅助功能保留完整名称。右侧为标准“发送”（默认按钮样式）／“停止”文字按钮。下一轮语义和快捷键说明在帮助与辅助功能中保留。Return 换行，⌘Return 发送，输入法组字期间不发送；提交失败保留原草稿。完整面板与键盘的隔离验证见[输入区与 Pi 发送任务](../../tasks/composer-pi-send/packet.md)，不代表真实提供商发送已验收。

各原生窗口与Tab持有独立AppStore工作区，共享一个Transport/application、配置、认证、问题和单活跃执行。只读历史与绑定来源会话的发送由UniFFI具名接口承载。窗口命令使用focused scene，不广播发送；Tab关闭不关闭核心。未发送草稿仅留在工作区，首发创建成功后立即保留原生身份，之后派发失败不自动重建或重发。验收见 [会话体验任务](../../tasks/mac-conversation-usability/packet.md)。

消息列表消费 Rust 产出的有序展示项与稳定身份，原子更新行、工作范围与大纲。assistant 正文经 swift-markdown 解析并映射为 TextKit 1 属性文本；围栏代码是独立布局元素，带圆角背景、语言标签与原生复制按钮。渲染结果按消息内容修订缓存，未变化轮询、离屏重入和 cell 复用不重新解析。工作过程、工具和推理使用行内 AppKit 原生 disclosure 按钮，开合只改变所在行。消息区域采用系统windowBackgroundColor不透明背景。Markdown链接交给系统注册的应用，相对文件以当前会话目录解析，失败由原生alert提供原文与复制。正文可在原生 NSTextView 内选择与复制；文本菜单首项“拷贝整条消息”复制该消息正文与通知的原文（不含推理和工具输出）。列表末尾保留固定留白，最后一条消息不贴住输入区。

消息容器是自有的翻转文档视图（NSScrollView 内），按需物化可见行与 overdraw 区域并复用纯 AppKit cell，不在行内承载 SwiftUI。未使用 NSTableView：它对未测行使用估计高度，并在任意 API 调用与布局中懒测量、自行重锚定，使高度在补偿之外落地。行几何是控制器高度列表的前缀和；每行布局由纯函数根据消息内容修订、局部展开状态与实际宽度计算，TextKit 1 测量与显示使用同一属性文本和容器配置，帧取整数，避免 layer 对齐改变已测宽度。可见带（视口上下各 0.75 屏）在显示前同步测量；其余行在后台队列按距阅读位置由近及远测量并分批提交。高度只在一次同步提交中变化，同时恢复视口顶部行及其行内偏移，阅读位置不随离屏行变化移动；`prepareContent(in:)` 为 responsive scrolling 预先物化。用户滚动离开底部即暂停跟随，滚回底部、点击回到底部或发送消息恢复。实施与验收状态见[会话阅读任务](../../tasks/mac-conversation-usability/packet.md)。

共享应用状态仅在值变化时发布到工作区；无匹配的轮询问题清理及相同会话快照不触发重复界面应用。正常空闲轮询消费内存快照，点击／滚动不直接读取历史文件。轮询携带上次交付游标，core 未变化时不传快照，变化时只传变化消息及完整顺序；映射在后台请求队列完成，主线程按消息身份合并。超过 2KB 的推理与工具输出只随快照携带大小，展开对应 disclosure 时按消息读取并在原位替换占位；同一交付 stamp 的已读内容在后续合并中保留。
