# Security reports

Report suspected vulnerabilities through GitHub's private vulnerability reporting. Include the affected version or commit, platform, relevant runtime versions, impact, and a concise reproduction. Share sanitized examples that demonstrate the issue. [Private report](https://github.com/xiaoland/velune/security/advisories/new)

The project maintainer reviews reports and coordinates fixes and advisories with reporters. Keep exploit details in the private advisory during that process.

Use public issues or Discussions for ordinary bugs and feature ideas. GitHub documents the private reporting process. [Reporting guidance](https://docs.github.com/en/code-security/how-tos/report-and-fix-vulnerabilities)
