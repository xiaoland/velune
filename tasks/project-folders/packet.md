# 多文件夹项目

## 已确认的产品意图

- 项目与单个文件夹解耦：一个项目可有多个文件夹，其中一个为主文件夹（[S35](../../docs/sources.md#s35)，产品归 [PRD](../../docs/prd/index.md#会话内容展示)）。
- Git worktree 中的会话归入其所属仓库的项目。

## 方案（开发方自主的工程选择）

- 项目以主文件夹标识：分组键、项目筛选与“移到项目”沿用路径，指主文件夹。只有被调整过（有名称或附加文件夹）的项目才有记录，其余目录仍是隐式项目。
- 组织记录 schema 2：`projectAliases` 改为 `projects`（主文件夹、可选名称、附加文件夹）。一个文件夹只属于一个项目。按 hard-cutoff，schema 1 的组织文件重新初始化（2026-10-17 本机统计：19 条已读进度、1 个别名，无置顶／归档／移动）。
- 会话归属：先排除无项目位置，再按文件夹记录归属，然后查 worktree 来源，否则就是工作目录本身。来源为本机会话的 `.git` 文件（`gitdir` 加 `commondir`），以及 Claude Code 约定的 `.claude/worktrees/<名称>` 路径；后者也覆盖 SSH 会话与已删除的 worktree。检测结果在进程内缓存。
- 改主文件夹或并入另一个隐式项目的目录时，把移动记录、项目筛选与折叠的分组键改指新主文件夹。
- Mac：“重命名项目…”改为“编辑项目…”，可设名称、添加或移除文件夹、设为主文件夹，并列出自动归入的 worktree（只读）。
