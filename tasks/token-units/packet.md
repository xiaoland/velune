# Token 单位

用户已授权更新各客户端的 token 显示和输入。修改限于界面格式与输入解析，核心仍保存整数；保留工作区已有的远控等改动，不纳入本任务提交。用户随后已明确授权提交本任务与覆盖安装。

Mac 与 Windows 有模型、模板、导入、会话用量和统计入口；Android／iOS 当前没有 token 数值界面。采用十进制 K／M／B，计数显示和编辑保持精确值，输入接受大小写单位、小数和规范千分位整数。空白仍表示未知，拒绝零、负数、非整数 token 和超出 UInt32 的模型上限；最大输出不能大于已知上下文。

依次实现各端共享格式与解析、接入全部调用点、补充跨端相同的边界断言，再构建并检查文档链接与 diff。验证应覆盖 1K、272K、1M、1.5M、8192 无损回读、非法及溢出输入、未知值和输出上限关系。

实现已完成：Mac／Windows 的全部已知入口已接入，包含模板、模型目录、导入预览、会话状态与轮次详情、统计及图表坐标轴。Android／iOS 经源码检索确认没有现存入口，不扩展新界面。共用输入规则同时守护提供商保存和保存为模板。

`bash scripts/check-token-units.sh` 已通过 Swift 与 C# 的边界断言、每端约 54 万个 UInt32 取样的无损回读、UInt64 最大值格式化和输出／上下文关系。脚本只使用已安装编译器及临时目录，无额外依赖。当前本机 .NET SDK 为 8，Windows 实际应用仍使用 .NET 10 构建。

构建验证使用 Mac 工作区和 win-ws 的独立验证副本 `C:\Users\yyh\velune-token-units`。Windows 副本来自当前 HEAD 与本任务 Windows 改动，未覆盖已有工作目录，也未复制真实用户数据。
