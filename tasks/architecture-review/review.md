# 实现审查结论与本轮纠正

完整改进清单见 [inventory](inventory.md)。此次按状态归属、原生执行生命周期、消息／窗口呈现、管理／调度和迁移五组检查实际调用路径，并追踪失败、迟到回包、重启与多个消费入口。

用户进一步要求核查长期变化成本与责任归属，续审及结构性纠正见 [结构复核](structure.md)。以下保留上一轮功能路径的发现，不能据此推断所有架构问题已解决。

## 上一轮判断

内容／目标配置分离、执行快照、消息角色与 turn 投影分离、统一 Artifact 承载、设备级管理队列和调度账本都有明确的寿命或业务依据，保留这些边界。问题主要出在同一保证只覆盖了部分入口，或者成功路径完成后没有把失败和恢复路径一并收拢。本轮把修复放回既有 owner，复用原有状态、进程树与持久目录。

## 已纠正的问题

| 问题 | 原有缺口 | 本轮纠正 |
| --- | --- | --- |
| 打开失败后的输入与会话身份 | 已切 composer，失败仅回滚列表选择 | 同时恢复未首发身份与原输入，后来的导航继续执行。 |
| 离表会话查找与目录加载 | 迟到 lookup 可夺回新目标，旧目标目录抢占后续打开 | 每次 lookup 有请求身份，后来的意图作废旧回包；先处理下一导航。 |
| 创建成功后的首发失败 | 仍把已归属会话的 InputID 归还全局新建项 | 按本次原生创建阶段恢复，保留已创建会话的输入。 |
| 返回旧运行时的推理与权限 | UI 和发送各自只看全会话末轮 | 共用最近匹配运行时的设置规则，最新未知项保持未知。 |
| 远端窗口移动与恢复 | WindowSeed 漏设备，journal 按类型混读所有设备 | 窗口携带明确执行设备，拖放／恢复共同核对；旧无归属快照只按精确 scene 身份恢复。 |
| Artifact 再次查看 | 只查原窗口，移动后会产生第二个对象 | 同执行设备的窗口共同查找内容身份，复用原对象和源码选择。 |
| 通知导航与可见性 | 零窗口时丢弃目标；旧会话焦点可误抑制通知 | 复用应用级会话打开路由，并按 key 窗口实际内容判断可见性。 |
| 删除失败与退出时的未保存文本 | 删除前先丢 pending；close 可能先于回包补写 | 成功后清理，失败后补写；退出等待先前管理结果结算再关闭。 |
| 定时任务忙时触发 | 有运行中记录就仅推进游标，遗漏承诺的一份等待 | 账本区分当前多目录调用与未来触发，最多保留一份等待。 |
| Pi 扩展启动与 steering | 历史查询消费 start 事件时未更新 busy | 轮询和历史同步共用同一事件生命周期入口。 |
| SSH 资源释放 | 裸 master 不管理后代，session 结束未立即释放 tunnel | 转发复用 ProcessTree，tunnel 随所依赖的原生进程释放。 |
| 远端 supervisor 进程组 | 回收 leader 后才清组，破坏 PID／PGID 生命周期保证 | 先无回收观察，清理进程组后最后回收 leader。 |
| 编辑／fork 的操作准入 | 展示可安排不等于当前可执行，无效编辑先 cancel | core 在运行中返回 Busy，UI 经既有 Transport 错误解析识别其操作包装；无效替换先拒绝，再考虑停止原轮。 |
| Composer 首次迁移的中断恢复 | 目录提交后缓存失败，重跑缺少恢复源而跳过 | 首导也保存组合恢复点，目录和缓存均可续接，保留身份与待同步选择。 |
| 文档规则分叉 | 旧按完整 InputID 保存配置、临时 runtime 和 reference 注入仍被描述为当前规则 | 对齐已确认的内容／目标分离、目标配置持久化及原生上下文翻译。 |

## 明确保留的实现边界

- 原生回显未提供跨全部 runtime 的提交 operation ID。本次没有证据证明现有控制权与 AgentSender 过滤下可达的错认，保留稳定 User 身份认领；按正文猜测会误伤附件和交接内容。
- RuntimeEditor 保存实例后另存该类型的新建默认。普通 API upsert 本身不写独立 composer 偏好。清空全部会话配置会违背已有状态归属；本轮撤回了这一候选。若将来需要跨文件原子保存默认，应在明确的默认归属契约下实施，不能用先清后存掩盖部分失败。
- 网络资源缺陷已修正，历史 ENOBUFS 归因仍开放。记录器有采样与保留窗口限制。
- 用户明确延后日常迁移／安装。旧设备归属不明的窗口恢复点保留原文件，无法凭会话 ID 自动判定设备。

## 验证入口

本轮仅补被修复的边界。运行时、输入和管理分组记录维护各自局部证据，Mac 统一构建后使用已有隐藏检查入口验证组合路径。最终结果汇总在 [packet](packet.md)；此前未受影响的跨端构建、视觉和实际合成运行时证据继续复用。
