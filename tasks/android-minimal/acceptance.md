# 统一远控人工验收方案

状态：2026-10-18 已收敛的验收方案，用户已恢复实施授权，当前进入 S1。本文件定义取证方式，不记录新通过项。技术契约以 [统一设备远控](../../docs/design/remote-access.md) 为准，执行次序归 [线性计划](plan.md)；锁定依赖的源码事实和临时实验见 [研究记录](transport-research.md)，已经发生的观察见 [verification](verification.md) 与 [Rust 远控验收](../remote-control/verification.md)。

## 判据、环境与证据

硬不变量是授权、身份、业务副作用和状态寿命约束；任意一次违反都失败，不能用平均恢复速度抵消。10／15／30 秒是本轮预先固定的工程验收预算，尚无真机通过证据，也不是生产 SLA。构建成功、进程存在、网络通知返回、无错误日志、最终连上，都不构成业务通过。

| 环境 | 前置条件与可以支持的结论 | 不能替代的证据 |
| --- | --- | --- |
| E0 隔离核心 | 临时私有 HOME、合成身份／Harness、可控制的存储失败与接纳／完成 gate；两执行端各有独立 owner | 平台相机、真实网络和后台行为 |
| E1 同 Wi-Fi 真机 | 隔离 Mac app 与已解锁 Android；真实 UniFFI／iroh；无 adb reverse／forward、VPN 或端口转发 | 公网打洞、CGNAT、蜂窝和跨运营商恢复 |
| E2 受控异网 | 两端分别处于独立公网出口；记录 IPv4／IPv6、NAT／防火墙条件、可达 relay；可控 AP／路由器用于变更与 UDP 阻断 | 未记录拓扑的“公网成功率”；真实 NAT 结论不能只由模拟路由取得 |
| E3 Android 多网络 | Wi-Fi LAN 与蜂窝同时存在，能确认默认 Network、各接口可达性；网络切换获准且流量有界 | 默认网络 callback 或接口枚举不能证明非默认 Wi-Fi socket 真正可用 |
| E4 可替换设施 | 两套可控 relay／lookup、可观察的访问日志和可选 Bearer 认证；可阻断旧设施及全部公共预设 | 本机修改 map 成功、公共 relay 可用不证明自部署闭环 |

每次运行先记录源码提交、APK／so／bindings／Mac bundle 摘要、依赖锁定版本、配置代际、环境编号与拓扑、操作序号和预先选定的观察窗口。只使用合成业务，不读取真实认证、会话或个人文件，不调用真实模型；未来临时人工脚本不进入自动化测试或 CI。

证据至少包含三方关联：当前 UI 或具名 SDK 返回状态、执行端真实副作用、请求／连接／世代身份。持久身份用本次运行的匿名别名关联；受控地址与接口的原始映射只存私有诊断资料，常规日志不含地址、消息、token、核对码、Bearer 或私钥。只记录核对是否一致，不记录核对码本身。

UI 每次读取必须取得新证据。uiautomator 先删旧 XML，检查明确成功输出；busy、null root、文件未更新都记为“观察不可得”，不能读旧内容判成功或失败。使用当前 screencap 交叉确认；邀请码显示时不截图、不输出 XML 正文。安装新包后记录新 PID 与产物摘要，旧包或诊断包结果不能直接转给最终包。

## 依次执行的功能门槛

正式功能验收先在 E0 闭合服务寿命、写入和方向配对，再接 E1 的扫码／最小 UI，随后完成 E2—E4 的业务矩阵。线性计划 S1 在此之前使用最薄传输探针完成 E1／E2／E3 风险判别；探针通过不能代替最终产品验收。后一个环境没有准备好时，完成独立项目并明确阻塞，不把未执行降成通过，也不通过绕过授权、强制绑网或频繁重连改变判据。

| 类别／环境 | 人工操作 | 必须取得的证据 | 通过／失败标准；依赖与未达处理 |
| --- | --- | --- | --- |
| UniFFI 装配，E0／E1 | 用同一契约生成 Kotlin／Swift；构建 remote-only Android；最终包覆盖安装冷启，再以本轮独立合成数据执行首次身份创建、重开和一次真实业务往返 | 构建摘要、APK 内 so、依赖树；身份文件模式与公开设备 ID 连续性；UI→UniFFI→Handler→副作用→UI 结果 | 不携带 application／Harness／gateway 执行栈；新身份完整私有、重开不变，无 API30 动态符号依赖于 API28；不能仅凭 run-as probe 过关。生成冲突或真实 app 域失败由原 owner 修复。清理仅限已确认属于本轮的合成数据 |
| 扫码与解析，E0／E1 | 手机离线识别 Mac 单码；相机拒绝／恢复、旋转、离开扫码页；显式选择一张合成二维码图片；输入畸形／超长／过期／不支持版本及伪装 URL | 解析状态、接纳长度、相机释放观察、无网络解码条件；真实手机识别时间与失败次数 | 所有导入进入同一结构化解析和确认流程，不执行任意 URL／命令；不静默多码或降级手工 JSON。编码目标 512 字节、硬上限 1024 字节；容量不替代实际可扫性。相机依赖先固定、构建，失败不能转称正常扫码已支持 |
| 方向授权与核对，E0／E1 | C 扫 H；双方独立派生显示码，H 通过本地可信入口确认；再尝试 H→C；另以两个带 Handler 的 E0 执行端检验反方向 | QUIC 认证身份、候选阶段、核对一致布尔值、持久 grant 方向、两方向真实业务接纳结果 | 扫码或持有 pin 不授权；仅明确批准的 C→H 可用，反向需另批。H 的身份来自握手，不能由正文冒充。controller-only Android 无 Handler 不能单独证明反向授权正确 |
| 配对隔离与限额，E0 | 改身份／角色／方向／attempt，重复同连接请求；并发发起超过邀请挑战预算，交错取消／换连接／换公钥 | context 与完整 binding 是否改变的布尔值；候选数量、原子挑战计数、拒绝原因；不输出码或 binding | 同一有效 attempt 幂等，其他绑定不可替用；总挑战预算不因重连／取消重置，不允许自己确认或列举其他候选。八位显示可能碰撞，不以“每次短码都不同”作错误判据；依赖已实现的配对状态机，primitive 样例不替代 |
| 配对中断与存储失败，E0，再 E1 冷启 | 在 pin／待确认保存失败、Ready 前后、确认与断线竞争、grant 原子落盘失败、提交后回执丢失处设 gate；重启控制进程或执行服务，查询原事务；另做同连接路径切换与真正 QUIC 关闭 | 两端持久状态、原事务 ID、是否 Ready、grant 提交点、连接身份、查询结果与业务拒绝／接纳 | 未提交则无授权且明确失效／可取消；已提交则可按原事务查询，不再消费邀请或再次批准。新连接使未提交旧挑战失效，同 QUIC 换路径不变；落盘失败不得显示 Granted。已撤销 grant 不能由旧事务复活。若无法安全控制提交点，先补隔离观测，不靠断网时机猜测 |
| 撤销与审批竞争，E0／E1 | 撤销当前设备后在旧连接、新连接和旧完成事务上操作；两已授权端同时回答同一真实 Harness 审批；再复用原生 raw ID 发新审批并提交旧回答 | 撤销提交顺序、每请求接纳点；Harness 实际收到的决定次数；新旧公开审批 ID、快照 | 撤销提交后不接纳新业务；已经接纳的副作用不假装撤回。审批恰一回答生效，另一端明确冲突；旧回答不影响新审批。无效授权／身份不符停止自动恢复，不降级为同名设备 |
| 服务与 Endpoint 寿命，E0／E1 | 启动 gate 延迟的合成写入；关闭／重开接入、重建网络端点或替换设施；分别保留与销毁服务／owner；Mac 停止入口后继续本地聊天及控制另一设备 | owner／服务／调用世代／网络代际／QUIC ID；原请求完成记账与副作用计数；网络资源退出屏障 | 端点重建、接入启停不换服务调用世代、不丢账本，不取消业务。仅停用入站控制不得误关出站；替换全部网络资源时完整等待唯一关闭屏障、释放旧 publisher／客户端／socket 引用。旧 DNS 记录仍存在不等于旧资源仍运行；不能用第二次 close 的返回当关闭证据 |
| 写入未知、回收、重启，E0，再 E1 | 丢弃已接纳写入回执，控制进程重开后查询原 ID；重提同 ID 同内容及冲突内容；在真实有界缓存回收后查询；分别重建 Endpoint 与重启业务 owner | 持久未决 ID、接纳／完成序列、业务副作用计数、完整结果／ResultExpired／Unknown／ServerRestarted | 同一已接纳请求只执行一次；结果过期、未知或新世代不构成重发许可；先刷新业务快照。Endpoint 重建仍查询同次结果；owner 重启用新世代，旧 ID 不执行。不宣称跨 owner 崩溃 exactly-once。回收要通过真实容量／时间边界触发，不凭伪造枚举通过 |
| 写前记录与 hard-cutoff，E0／E1 | 对上传、认证控制、配置和会话副作用分别阻断 pending 保存；确认终态记录时模拟保存失败；用合成旧 schema 启动，再损坏独立合成身份文件 | 发送前门禁、网络／Handler 接纳计数、未决状态；原身份公开 ID、重置通知及当前 schema | pending 保存失败则零发送；确认保存失败保留记录，上传等不能遗漏。旧普通 schema 原子重置且通知跨冷启保留，身份保持；旧未知操作不重发、不伪装未执行。损坏身份明确失败，不生成新钥匙；不以真实用户数据做此项 |
| 完整业务 SDK，E0／E1 | 按当前 Command／具名 API 导出清单逐项标记适用 fixture；覆盖会话、消息读取／编辑／组织、模型／提供商／运行时、资源／二进制附件、变更与 diff、交互／协作；加入修订冲突与无权输入 | 每项入口对应的真实 Handler 结果与应用／Harness 观察；边界失败类型、修订与合成秘密泄漏检查 | 全业务指既有 Velune 能力，不能以几个聊天方法代表，也不扩大为通用终端／任意文件访问。列表／Debug／日志无秘密，显式秘密读取仍可用；路径属于执行端，越界拒绝。不能用本地直接调用代替远端 SDK 路径；真实供应商行为另由用户验收 |
| 最小 Android UI，E1 | 从扫码到确认、可信设备列表；读取历史／展开消息，新建并选已有运行时／模型，发送／回复／停止，审批及问题回答；显示待确认请求并查询原 ID；断开／重连／移除联系人 | 最终包新鲜界面／截图、可访问标签与键盘布局；真实执行端副作用、原请求查询、选中设备与代际 | 界面与核心状态一致；用户／LLM 无头像昵称；键盘不遮挡必需操作；未知写入只查询不盲重发。不要求本切片复制完整配置 UI，完整 SDK 验收仍独立保留。此前欢迎页／进程观察不能复用为此项通过 |
| 后台与恢复，E1／E3 | 合成 turn／审批期间进入后台、熄屏、force-stop 控制应用；执行端完成后前台恢复；恢复同时改选设备或设施，制造旧连接晚到 | 执行端独立完成、保留审批；前台快照／未决 ID、连接意图与恢复循环数量；相机和观察任务寿命 | 控制生命周期不取消执行；同设备一个有界退避恢复循环，旧结果不能覆盖新意图；后台暂停相机／观察不要求常驻。owner 真退出后的 Harness 状态必须重新读取，不能外推继续执行。短时实验不证明系统长期后台策略 |

## 寻址、多路径与设施矩阵

下表每项同时施加有序号的低流量合成业务往返，并保留一个可查询的写入；传输探针只辅助定位，不替代业务观察。必须分别记录候选到达、探测／建立、实际 selected、恢复可用的时间；分段字节增量须支持实际使用路径的判断。

| 环境与操作 | 证据与通过标准 | 依赖、失败分流与边界 |
| --- | --- | --- |
| E0 陈旧 descriptor／仅 ID；E1 公共设施不可用的同网重连 | 固定同一公钥，去掉有效旧地址，观察实际 lookup／mDNS 返回新候选并认证往返；联系人与 grant 不重建 | 仅 ID 依赖已知 lookup 入口；mDNS 依赖编译、多播与平台实测。Disabled＋Pkarr 当前不保证直接 IP 发布；缺少 locator 应明确提示更新连接资料，不误报未配对 |
| E1 mDNS 显式接口与资源寿命，S1 探针先行 | 保持同一 Endpoint／连接，受控接口集合 A→B→空→B；关联发现代际、publish、fresh resolve、失效通知和本进程 socket 退出。空集合无默认多播回落，旧 callback 不重新填入缓存；稳定重复事实不重建 | 默认路由存在隧道时以同协议／身份／广告的 LAN 正对照定位，不修改系统隧道。仅有一个 LAN 时先做 A→空→A，实际 A→B 仍记缺少环境；手工 setter 只验证库生命周期，不代替平台自动事实装配。返回 ack、移除 actor 引用或发出 abort 均不是资源已退出的证据。IPv4 不代替 IPv6 |
| E2 同网首次添加后分别异地，两端随后都换网 | 记录独立公网出口及换网事件；旧线索失效后重新发现，同一身份／授权恢复；未知写入按原 ID 查询 | 现有同 Wi-Fi 手机不能完成此项；必须准备真实异网。受控 NAT 是定位手段，不能发布为跨 NAT 成功率 |
| E2→E1→E2，持续 WAN→LAN→WAN | 认证连接仍活时不主动拆连；验证新 LAN 地址从发现到实际探测／选中，离开后旧路径失效并恢复；关联 QUIC ID、path 临时 ID、来源、接口／地址族、RTT、分段字节与业务最大空窗 | Direct 标签不能区分 LAN／公网；现映射不足则先补安全诊断。晚到 lookup 入缓存不是通过，必须出现探测与实际数据；若 QNT 接线未发生先修发现／广告，socket 不可达修平台，路径可达却不选择才研究 selector；不能频繁重连掩盖 |
| E2 在已有 Direct 下阻断 UDP，恢复 UDP | 保持 relay TCP／TLS／WebSocket 及 lookup 可达；实际 Direct→Relay→Direct、业务恢复时间和未重复写入；记录是否同 QUIC 或有受控重连 | 路由器阻断策略／计数证明故障真的生效，不能只用 RelayOnly 模式充当回落。relay 不可达应给可诊断失败，不能无限恢复中；解除故障后“最终连回”仍须满足已冻结的时间预算 |
| E2 接近 RTT／LAN 丢包 | 受控延迟／丢包前后观察实际选路、切换次数、业务 RTT／空窗；确认没有重复写入或多连接业务 owner | 锁定原生 selector 并非全局最低 RTT／丢包优化；记录已知策略与退化，不把私网地址或理论 RTT 当最优证据。只有稳定可达的更好路径未被选中才进入策略判别 |
| E3 蜂窝默认而 Wi-Fi LAN 可用；Wi-Fi 有链路无 Internet；真断开；仅 DNS 变化 | 分别记录默认 Network、两网存在性、受控 LAN 服务可达、socket 实际接口与业务往返；不能只记录 callback。恢复不破坏仍可用 LAN／公网路径 | 当前 Android 调用链无逐 Network socket 绑定，属于实施判别项。先完成 E3 才能决定平台适配；不得以全进程强绑 Wi-Fi 或增加选网模式静默缩小目标 |
| E4 更换 home relay／认证 token／Disabled→启用 | 分开观察“保存”“网络代际应用”“业务连接”；新代际维持服务／账本，明确旧设施关闭后阻断旧服务仍能连接；token 只发规范配置的认证目的地 | map 更新不证明旧 actor／token 已退出。不同两端 home relay 也须实际互通；邀请／公开地址无 Bearer。准入失败与配对失败区分，lookup 任意返回 URL 不携带默认 token |
| E4 替换 lookup，全自部署及离线联系人交接 | 在线联系人先取得新入口，离线联系人未获得入口时给明确资料缺失；带外更新仍固定原公钥；禁止公共预设的受控出站条件下完成真实业务 | 停用 publisher／TTL 到期不证明所有联系人已更新，不要求无限保留旧入口。完整自部署须 relay、lookup、准入都具备；没有设施环境则此项阻塞，不能用默认服务回落取得假通过 |

## 测量窗口、结果与收口

每个场景先固定版本、拓扑、业务节奏和故障点，记录 60 秒稳定基线、最多 180 秒转换观察、恢复后 60 秒连续业务；首轮每类做三次独立转换，报告每次结果、中位数、最大值与超时，不用小样本推算公网成功率或尾部分位数。180 秒只是有界诊断窗口，以下预算超出即失败，随后连上不得改判。

| 场景与前提 | 冻结的工程预算 | 计时起点 → 通过终点 |
| --- | --- | --- |
| 已有连接进入可达 LAN；预先确定 LAN 路径满足原生策略的优选条件 | ≤10 秒 | 平台报告 LAN 接口及地址可用 → 新 LAN 路径被选中并承载一次成功合成业务往返 |
| 当前路径失效，另有已验证可达的备用路径 | ≤15 秒 | 受控故障实际发生 → 备用路径承载一次成功合成业务往返 |
| 需要重新拨号或控制应用回到前台；目的设备和至少一条允许路径可达 | ≤30 秒 | 前台与可用网络条件均具备 → 完成认证、刷新业务快照并查询原未决请求 |

平台开始计时不能延后到 iroh 已经收到候选；故障开始不能延后到库上报断线。恢复不要求远端任务完成，但必须取得新鲜业务响应，Running／Unknown 等明确查询状态也可作为真实响应。身份、授权、业务副作用和原请求标识仍须满足硬不变量；网络前提不成立应留下独立可达性证据并记环境阻塞，不以“网络不好”解释任何超时。

至少测量：发现延迟、首次探测延迟、路径选中延迟、可用业务恢复延迟、最长连续无回执时间、重复／乱序副作用数、配置退出屏障完成时间，以及扫码开始至解析时间。人工核对等待与故意 gate 保持时间单独列出，不混入网络性能。成功连上但超过观察窗，记“本窗口未恢复”；没有足够路径／接口证据，记“路径结论不可得”。缺证据与产品失败分别记录，但两者都不能签为通过。

S1 校验计时方法、实验环境和锁定定时器，不按首次测量结果修改上述预算，也不追加一次默认用户审批。超时回到平台通知、QNT、路径退出或业务恢复的对应修复分支。只有新证据改变原前提时才作带理由的设计修订并重验；实质削弱已确认体验目标的修订须回到产品决定，不能为了某次失败放宽门槛。接近 RTT 的实验不得出现由应用层主动反复重连造成的抖动；扫码在预先记录的显示尺寸、距离与照明条件下重复成功，报告每次识别时间和失败，现场观察仍属于用户体验验收。

每项记录为“通过／失败／阻塞／未执行”，附操作、环境、产物、关联证据和原因。通过只覆盖同版同条件，源码或装配改变后由影响范围决定重验，不能把诊断包、旧 UI 或更简单网络的结论套用。完成后关闭合成服务和相机、清理本轮临时网络／设施规则，只移除明确属于本轮的手机合成联系人／未决资料并回到欢迎页；不清用户其他数据，不启动真实 app／模型。持久结论回归技术文档，实际观察追加 [verification](verification.md)，本方案不复制历史报告。
