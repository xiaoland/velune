# 运行时与网关门禁复核

2026-10-08 用户明确：注册 Velune 网关用于不同 Harness 共享模型、聚合订阅与提供商，不代表运行时只能使用该网关。此次复核覆盖 Pi SDK 装配、原生子进程装配、LLM gateway 请求准入及提供商配置校验；不是对仓库所有条件分支的删除。

root 提出清单，pi_provider_boundary_advisor 重新判断，Pi 与 AI 稳定 owner 实施。此前 advisor 将默认网关注入扩成禁止扩展更改行为的建议已撤回。

| 清理对象 | 原限制的问题 | 处理 |
|---|---|---|
| Pi provider/native provider/virtual 注册拦截、保留名称拒绝 | SDK 正常注册被额外政策阻止 | 删除 |
| __veluneOwned 与冲突状态 | 自建注册门禁的配套协议 | 删除 |
| streamSimple 目标快照检查、model.api 断言 | 把网关强制为唯一入口 | 删除 |
| Pi 空认证存储、替代来源模型目录 | 原生提供商虽可注册但不能正常消费原配置 | SDK 消费来源配置，追加网关 |
| 子进程环境白名单 | 用户配置的原生环境能力被屏蔽 | 恢复进程环境继承 |
| DSH 禁用 settings/原生 LLM 插件 | 为防来源覆盖路由禁用能力 | 删除禁用项，保留追加网关及初始选择 |
| 全局 subscription payload 与模型 state hook | 原生请求也被 Velune 选择影响 | 只处理 Velune 模型 |
| gateway 256 KiB 请求限额、16 并发拒绝 | 正常长上下文、图片与并发被任意限制 | 删除 |
| 三原生协议请求256 KiB、JSON响应16 MiB、Responses待发事件256 KiB | 合法协议内容被adapter任意截断门槛阻止 | 删除，保留实际解析及终态语义 |
| 转换请求/响应累计16 MiB、RPC记录1 MiB、历史结果16 MiB | 合法业务内容被字节常数拦截 | 删除业务容量拒绝，保留流式背压 |
| 交接256 KiB、公开目录16 MiB | 任意容量代替实际模型/目录能力 | 删除，不截断内容 |
| RPC控制响应前事件数64、认证答复/结果大小 | 正常事件或登录内容被任意数量拦截 | 删除业务拒绝，保留状态关联和诊断缓存 |
| Pi上下文窗口/输出上限必填 | SDK已有缺省处理仍强制用户补规格 | 可未知，交给SDK原生缺省 |
| 上游 60 秒空闲读取超时 | 正常长推理被误判失败 | 删除；取消和退出仍中止派发 |
| 单变体 failover 判断、局部记录键去重 | 不可达或已被更强的配置入口校验覆盖 | 删除 |
| build_routes 重复全量验证与反向查找 | 已验证不可变配置仍逐条重验 | 直接使用正在迭代的条目 |
| application 派发时全量配置重验 | 已在加载/保存入口校验，重复阻断无关目标 | 派发只查目标归属 |
| 修改协议要求确认并手动清除来源参数 | 阻止正常可编辑协议操作 | 自动清除旧协议派生参数，共性字段保留 |
| 准备网关时要求全部提供商认证已就绪 | 无关未配置目标阻止整个网关 | 实际请求再由 resolver 解析认证 |
| 输出上限不得大于上下文窗口 | 把推测关系作为所有提供商定律 | 删除比较，保留零值参数错误 |

仍保留实际执行所需的边界：路径、文件与 JSON 解析；外部运行时版本/协议适配；模型和路由目标存在性；唯一记录键/别名；HTTP 网关认证与 OAuth 目标绑定；连接及请求体读取期限；RPC 进程关闭和取消；原生工具审批。它们解决具体请求构造、身份、状态或生命周期问题，不用于强制只准使用网关。

导入的尚未实现协议、自定义请求头与兼容字段诊断代表当前转换/表示能力缺口；不能删除错误然后悄悄丢掉用户字段。开发工具仍不得读取真实秘密或会话；这不限制应用通过原 SDK 使用用户自己的来源配置。

验证结果和安装提交状态由 packet.md 当前进展记录。清理不是把错误伪装为成功，也不引入新的防覆盖、防绕过机制。
