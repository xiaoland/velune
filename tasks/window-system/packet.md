# 窗口系统

2026-10-14 用户要求改进窗口系统：多窗口、窗口内平铺、工具窗口的停靠／浮动／吸附，让用户由浅入深地高效工作。决定见 [S25](../../docs/sources.md#s25)；2026-10-15 首轮验收后改为按统一布局模型重建，见 [S26](../../docs/sources.md#s26)。产品归 [PRD](../../docs/prd/index.md#多窗口与-tab)。

## 已确认的产品意图

- 窗口内分屏会话：左右／上下拆分，每个面板有自己的会话、输入区与运行状态；面板可拖出成独立窗口，也可拖回。多窗口、原生 Tab 与系统窗口平铺继续可用。
- 工具窗口只有会话列表、会话大纲与输入区（composer）；可停靠、浮动或隐藏。浮动面板贴近主窗口边缘或彼此时吸附，吸附后随主窗口移动；拖入停靠区即停靠。
- 布局自动恢复，没有命名布局。
- 不做：变更审阅（暂缓）、跨会话活动面板（后续由“任务”层级承担）、任意内容可停靠组合。默认形态保持现在的简单样子，进阶能力按需出现。

## 现状（2026-10-14）

- `WindowGroup` 的每个窗口／Tab 持有一个 `AppStore` 工作区（`makeWorkspace`），它同时承担会话列表状态（列表数据由应用级 store 复制，搜索、多选、浏览偏好）与打开的会话（快照、转录、composer、下一轮选择、草稿）。
- `VeluneRootView` 是 `NavigationSplitView`：侧栏为会话列表，详情为转录＋输入区，工具栏有新建、显示菜单、重新读取与大纲按钮；大纲由设置决定为 popover 或就地折叠。问题、资源库、分析是单例窗口。
- core 已支持多个会话同时执行与多个工作区各自读取快照，分屏不需要改 core。

## 方案

- 每个窗口有一个窗口模型：面板拆分树（叶子是面板，节点是带方向与比例的拆分）、聚焦面板、工具窗口状态。每个面板持有自己的 `AppStore` 工作区，转录、输入区、大纲与下一轮选择都属于面板。
- 会话列表属于窗口：列表、搜索、浏览偏好与多选由窗口的列表工作区承担，单击会话在聚焦面板打开；聚焦面板的会话在列表中高亮。
- 只有一个面板时与现在完全一样；拆分后每个面板顶部出现一条细的标题栏（会话标题、关闭），聚焦面板以系统强调色标出。窗口工具栏作用于聚焦面板。
- 布局（拆分树、各面板的会话、工具窗口状态与浮动位置）随窗口经系统状态恢复保存（`SceneStorage`）。

分步实施：

1. 面板拆分：向右／向下拆分、关闭面板、聚焦与命令路由、列表打开到聚焦面板、行菜单“在右侧拆分打开”“在新窗口中打开”、布局恢复。
2. 拖动面板：在窗口内重排、拖出窗口成为新窗口、拖入另一窗口。
3. 工具窗口：会话列表停靠／浮动／隐藏；大纲在 popover、就地折叠之外增加停靠（面板右侧）与浮动；composer 停靠（每个面板底部）或浮动（一个浮动输入区，发往聚焦面板）；浮动面板吸附、跟随主窗口，拖入停靠区即停靠。

## 重建方案（2026-10-15，S26）

首轮的问题不在某个控件，而在没有统一模型：三个工具窗口各有一套放置枚举，停靠位置写死（列表只能在侧栏、大纲只能在右侧、输入区只能在面板底部），编辑区一个面板只能有一个会话，入口只有菜单里的单选。重建后：

- 窗口＝编辑区＋左／右／底三个停靠区。左区用 `NavigationSplitView` 侧栏，右区用 `inspector`，二者保留系统的材质、标题栏分隔与开关命令（显示边栏 ⌃⌘S、`InspectorCommands` 的显示检查器 ⌃⌘I）；底区在编辑区下方，自行绘制，⇧⌘Y 开关。区内多个工具窗口沿区的方向排列并可调比例；区内不止一个工具时各有一条标题条，带菜单可移到别处。不改用 AppKit `NSSplitViewController`：嵌在 SwiftUI 窗口里时侧栏材质与标题栏行为需要自行复刻，得不偿失。
- 工具窗口共用一套状态：位置（停靠在某区、浮动、独立窗口）、是否显示、浮动／独立窗口的位置尺寸；停靠区各有收起状态，工具可见＝显示且所在区未收起。“只显示编辑区”（⇧⌘↩）收起全部停靠区并能恢复。各工具另有一个“内置”位置：大纲为工具栏按钮的弹出／就地折叠，输入区为每个面板各自一个；共享输入区不可见时，面板恢复各自的输入区，任何时候都有输入区。
- 浮动＝utility 面板（随窗口、吸附、应用失活时隐藏）；独立窗口＝普通窗口（进入 Mission Control 与“窗口”菜单，可全屏，不并入工作区 Tab）。两者标题栏右端有同一个菜单：停靠到左／右／底、浮动／独立窗口。浮动面板拖到窗口左、右、底缘即停靠到该区。
- 编辑区为分屏树，叶子是标签组。标签栏仿照系统 Tab Bar（等宽、标题居中、悬停出现关闭、末端“＋”），只有一个标签且未拆分时不显示，默认外观不变；标签可拖到其他标签组、拆分落点、其他窗口，拖到窗口外成为新窗口，移动时会话的工作区原样转移。双击标签就地重命名会话。列表单击在聚焦标签就地打开（已在某个标签中则切换过去），新标签页 ⌘T、关闭标签页 ⌘W（最后一个即关闭窗口）、⇧⌘] ／⇧⌘[ 切换标签；⌘D／⇧⌘D 拆分，⌘] ／⌘[ 切换分屏。会话窗口不使用系统窗口 Tab（见下方进度）。
- 布局按新结构保存；旧的 `paneLayout` 不再读取（hard-cutoff）。

分步：A 统一工具窗口模型、三个停靠区、四种模式与入口；B 标签组；C 工具窗口聚焦快捷键与停靠工具标题条拖动等打磨。

## 验证

静态检查与 Mac 构建；隔离 `VELUNE_HOME` 后台启动、合成会话，用 AX 操作与窗口截图核对布局、聚焦与命令路由，不把应用带到前台。拖动与吸附需要用户界面验收。
