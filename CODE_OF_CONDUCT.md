# Community standards

Velune welcomes people who use, discuss, and contribute to the project. Keep participation respectful and focused on the work.

## Expected behavior

- Keep disagreements focused on ideas and evidence, and treat people with consideration.
- Share technical context in a way that helps others participate, including when you are new to the project.
- Respect privacy. Do not publish another person's private information, credentials, account state, or session data.
- Accept that maintainers may defer, decline, or narrow a proposal based on project scope and capacity.

## Unacceptable behavior

Harassment, threats, discriminatory or sexualized abuse, doxxing, impersonation, repeated personal attacks, and publishing private data or secrets are not acceptable. Do not use project channels for spam or to mislead people about Velune's affiliation with other projects or vendors.

## Reporting and moderation

Use GitHub's report action on the relevant issue, discussion, pull request, comment, or account. If GitHub offers **Report to repository admins**, use it for conduct concerns. Otherwise use **Report abuse to GitHub Support**. See [GitHub's reporting guidance](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam).

The project maintainer can review reports delivered through GitHub and may remove or edit content, close or lock a conversation, or restrict participation where the repository tools allow. GitHub Support handles reports sent to GitHub.
